## 启动与界面概览

启动 MediaForge 后，界面由三个区域组成：

```
┌─────── 标题栏 ─────────────────────────────────┐
│ MediaForge Logo   FFmpeg 状态   窗口控制按钮   │
├──────────┬─────────────────────────────────────┤
│          │                                     │
│  侧边栏  │          主内容区                    │
│  (导航)  │          (当前功能页)                │
│          │                                     │
└──────────┴─────────────────────────────────────┘
```

**侧边栏导航项**：

| 图标 | 功能 | 说明 |
|------|------|------|
| ⇄ | 格式转换 | 单文件转码 |
| ✂ | 视频裁剪 | 精确剪切片段 |
| ☰ | 批量处理 | 多文件同时处理 |
| ℹ | 媒体信息 | 查看文件详细信息 |
| ⚙ | 设置 | 路径与版本配置 |

> 侧边栏底部有 **亮色/暗色模式** 切换开关，偏好会持久保存。

## FFmpeg 状态检测

标题栏右侧显示 FFmpeg 状态指示：

- 🟢 **绿色"FFmpeg 就绪"** — 检测成功，可以正常处理媒体。
- 🔴 **红色"FFmpeg 未检测到"** — 未找到 FFmpeg，处理功能不可用。

> 如果显示未检测到，请前往 [设置](#设置) 手动指定 FFmpeg 路径，或在系统中安装 FFmpeg 后重启应用。

## 格式转换

### 基本步骤

1. 点击侧边栏「格式转换」。
2. **选择文件**：点击上传区域或将文件拖入区域，支持主流视频/音频格式。
3. 配置转换参数（见下方说明）。
4. 点击「选择输出路径」，选择保存位置与目标文件名。
5. 点击「开始转换」，进度条实时显示处理进度。
6. 完成后点击「在文件夹中显示」可直接跳转到输出目录。

### 可配置参数

| 参数 | 说明 |
|------|------|
| **输出格式** | mp4、mkv、avi、mov、webm、mp3、aac、flac、wav 等 |
| **视频编解码器** | 自动（auto）、H.264、H.265/HEVC、VP8/VP9、AV1、stream copy 等 |
| **音频编解码器** | 自动（auto）、AAC、MP3、Opus、FLAC、stream copy 等 |
| **视频比特率** | 如 `2000k`、`5000k`（留空使用默认） |
| **音频比特率** | 如 `128k`、`320k`（留空使用默认） |
| **分辨率** | `1920x1080`、`1280x720`、`640x480`（留空保持原始） |
| **帧率** | 如 `24`、`30`、`60`（留空保持原始） |
| **硬件加速** | 无、VideoToolbox（macOS）、NVENC（NVIDIA）、QSV（Intel）、VAAPI（Linux） |

> **stream copy** 模式：跳过重新编码，直接复制流，速度极快但不变更编码格式。适用于仅换容器格式（如 mkv→mp4）。

### 取消转换

转换过程中，点击「取消」按钮即可立即终止当前任务。

## 视频裁剪

### 基本步骤

1. 点击侧边栏「视频裁剪」。
2. **选择文件**：点击上传区域或拖拽视频文件。
3. 文件加载后，下方显示**视频预览**及**时间轴滑块**。
4. 拖动时间轴设置**开始时间**与**结束时间**。
5. 点击「选择输出路径」选择保存位置。
6. 点击「开始裁剪」，等待完成。

### 注意事项

- 裁剪默认使用 **stream copy** 模式（无损、快速），输出格式与原文件相同。
- 由于 stream copy 基于关键帧，实际裁剪位置可能与设定值有±1秒误差（视频文件的关键帧间隔决定）。
- 视频预览使用 `media://` 自定义协议安全加载本地文件，无需外部服务器。

## 批量处理

### 基本步骤

1. 点击侧边栏「批量处理」。
2. **添加文件**：点击区域或拖拽多个文件，支持一次导入多个视频/音频。
3. 在文件列表中可**删除**单个文件（点击 × 按钮）。
4. 选择输出目录（所有文件将输出到同一目录）。
5. 配置统一的**输出格式、编解码器**等转换参数。
6. 点击「开始批量处理」，每个文件显示独立的状态（等待中 / 处理中 / 完成 / 失败）。

### 批量处理规则

- 输出文件名：`原文件名 + _converted + 新扩展名`，例如 `video.mp4` → `video_converted.mkv`
- 若某个文件处理失败，其余文件继续进行，不会全部中止。
- 顶部进度条显示整体完成百分比。

## 媒体信息

### 基本步骤

1. 点击侧边栏「媒体信息」。
2. **选择文件**：点击上传区域或拖拽任意媒体文件。
3. 应用调用 ffprobe 分析文件，展示以下信息：
   - **格式信息**：容器格式、时长、文件大小、总比特率、流数量
   - **视频流**：编解码器、分辨率、宽高比、像素格式、帧率、比特率
   - **音频流**：编解码器、采样率、声道数、声道布局、比特率
   - **字幕流**：字幕格式、语言、标题

### 字幕操作

在媒体信息页面，检测到字幕流后，可以：

- **提取字幕**：将指定字幕流导出为 `.srt` 文件。
- **嵌入字幕**：将外部 `.srt` 字幕文件写入视频容器（生成新的 `.mp4` 文件）。

### 跨模块共享

媒体信息模块使用 **SharedFileContext** 与其他模块共享当前文件。在格式转换或视频裁剪中选择的文件，切换到媒体信息时会自动加载，避免重复选择。

## 设置

### FFmpeg 路径配置

若系统中 FFmpeg 未被自动检测到（如自定义安装路径），可在设置页面手动指定：

1. 进入「设置」页面。
2. 在「FFmpeg 可执行文件路径」输入框中填入 `ffmpeg` 可执行文件的**完整路径**。  
   示例：
   - macOS/Linux: `/usr/local/bin/ffmpeg`
   - Windows: `C:\ffmpeg\bin\ffmpeg.exe`
3. 点击「应用路径」。
4. 应用会自动在同目录查找 `ffprobe`（规则：将路径中的 `ffmpeg` 替换为 `ffprobe`）。
5. 状态区域会立即更新，显示新检测到的版本信息。

### 版本信息查看

设置页面底部显示当前检测到的 FFmpeg 版本与路径，以及应用本身的版本号。

## 文件拖放说明

MediaForge 所有上传区域均支持拖拽文件：

- 将文件从 Finder / 资源管理器 / 文件管理器，直接拖入应用的虚线上传框中即可加载。
- 由于 Electron 的 `contextIsolation` 安全限制，拖放文件的原始路径通过 `webUtils.getPathForFile()` API 安全获取，无需禁用任何安全选项。

## 常见问题

### FFmpeg 未检测到，但我已经安装了

**原因**：Electron 应用启动时的 PATH 环境变量可能与终端不同，尤其在 macOS/Linux 下通过图形界面启动时。

**解决方案**：
1. 在终端运行 `which ffmpeg` 找到完整路径
2. 在「设置」页面手动填入该路径

### 转换完成但文件无法播放

- 检查目标格式与编解码器是否兼容（如 `.mp4` 容器需要 H.264/AAC 编码）。
- 尝试去掉比特率/分辨率等限制，使用默认参数重试。
- 查看是否有硬件加速选项，某些 GPU 驱动版本可能不兼容，尝试关闭硬件加速。

### 视频裁剪的精度问题

视频裁剪使用 stream copy（不重新编码）时，实际裁剪点会对齐到最近的关键帧（I 帧）。若需要帧级精度，需将视频编解码器设置为 `libx264`（重新编码），此时速度会较慢。

### windows 下应用启动时出现 SmartScreen 警告

这是因为应用未经过代码签名。点击「更多信息」→「仍要运行」可继续使用。正式发布版本推荐配置代码签名证书。
